## Algoritmo

Un algoritmo es una secuencia ordenada y finita de instrucciones o pasos lógicos diseñados para realizar un cálculo, desarrollar una tarea o resolver un problema específico, estos son la base de la programación y permiten la automatización, eficiencia y procesamiento avanzado de instrucciones. Estos se utilizan principalmente para diseñar programas que ejecuten tareas específicas.

Un ejemplo de algoritmo es preparar café:
1. Calentar agua
2. Poner café en la cafetera
3. Verter agua
4. Esperar
5. Servir

Así se demuestra que es una secuencia ordenada de pasos diseñados para resolver un problema.

## Pseudocódigo

El pseudocódigo es la representación escrita de un algoritmo, utiliza un lenguaje de programación con estructuras similares a lenguajes reales (escribir, leer, si-entonces), este sirve para organizar las tareas que debe seguir un programa para su correcto funcionamiento.

## Diagrama de flujo

El diagrama de flujo es un tipo de diagrama que explica visualmente un proceso o flujo de trabajo, es prácticamente una representación gráfica y secuencial de un proceso, sistema o algoritmo. 
Usa una serie de símbolos o figuras que representan cada tipo de paso dentro de un proceso y cada una tiene una función específica:

<img width="320"  alt="image" src="https://github.com/user-attachments/assets/fe29fbaf-c882-4bfa-aa08-52715e647fae" />
<br>
Un diagrama de flujo sirve para simplificar la comprensión de un algoritmo, ya que, al ser una herramienta visual, el proceso se presenta de forma ordenada. También permite explicar ideas fácilmente y detectar errores más rápido.

## Prueba de escritorio

Una prueba de escritorio es un proceso manual esencial en el desarrollo de software, permite simular la ejecución de un algoritmo para analizar su comportamiento sin ejecutarlo en el computador, prácticamente es una tabla en donde se anota los datos de entrada, proceso y salida.

## Lenguajes de programación
Un lenguaje de programación es un conjunto de reglas gramaticales que se utilizan para dar instrucciones a una computadora, una persona habla con lenguaje natural mientras que, un lenguaje de programación está destinado a las máquinas. Ambos lenguajes tienen similitudes como que ambos tienen una sintaxis que deben seguir.

Estos se clasifican en:

1. Lenguaje de bajo nivel
<br><br>Están diseñados a medida del hardware, siendo necesario conocer las características de los componentes para aprovecharlos al máximo. Aquí se encuentran dos tipos de lenguaje:

- Lenguaje de máquina: Ordena a la máquina las operaciones fundamentales para su funcionamiento. Es un lenguaje mucho más rápido pero también más difícil de manejar, utiliza solo ceros y unos.
  
- Lenguaje de ensamblador: Representa simbolicamente los códigos de máquina binarios específicos de una arquitectura de procesador, utiliza una combinación de letras y números. Su principal ventaja es que el código es más corto y no ocupa tanta memoria.

2. Lenguajes de alto nivel.
<br><br>Es el más cercano al lenguaje humano, por lo que es bastante entendible; utiliza conceptos y tipos de datos sencillos. No dependen de la computadora, por lo que es posible migrarlos y seguir trabajando en otra máquina. Hay que utilizar un compilador para traducir el código al lenguaje de máquina.
<br><br>Entre los lenguajes imperativos, se encuentran Pascal y C; en el lenguaje declarativo, están Lisp y Prolog; para la programación orientada a objetos, Smalltalk y C++.

3. Lenguajes de medio nivel
Se encuentra en un punto medio entre los dos niveles de lenguajes de programación anteriores, cuenta con características de lenguaje de bajo nivel y mantienen un mayor nivel de abstracción.
Un ejemplo de lenguaje medio es el lenguaje C ya que cuenta con características de lenguaje de alto y bajo nivel.

4. Lenguaje Compilado e Interpretado.
<br>Los lenguajes compilados son lenguajes de programación en los que el código fuente se traduce a código máquina mediante un compilador antes de su ejecución. Al proceso de traducción se lo conoce como compilación y da como resultado un archivo ejecutable que puede ejecutarse en un ordenador. 
Algunos de estos lenguajes compilados más conocidos son C, C++ y Cobol
<br><br>El lenguaje interpretado es aquel que ejecuta el código directamente y no necesita ser compilado previamente. Esto se hace a través de un intérprete, que lee y ejecuta el código de manera continua.
Entre los lenguajes interpretados más conocidos se encuentran JavaScript, Python y PHP.

## Programación por bloques
La programación por bloques es un método visual para crear software arrastrando y encajando piezas gráficas como bloques. Es un método simple para comenzar y reduce el tiempo de aprendizaje inicial.
<br><br>Los lenguajes de programación por bloques actuales clasifican los bloques en categorías, utilizando un color distinto para bloques de cada categoría. 
Dentro de cada categoría existe una cantidad de bloques limitada, con estos bloques se puede hacer infinidad de combinaciones y construir muchos programas distintos.

# Reflexión Crítica

Se puede comprender la importancia de estructurar correctamente la lógica antes de programar, ya que los algoritmos son muy necesarios y el análisis de los problemas también, pues sin hacer un análisis no se puede identificar correctamente los datos de entrada ni los de salida, ni el tipo de proceso que se debe seguir o que problema intentas resolver.

Así mismo, es importante saber los conceptos principales de programación pues así se puede comprender mejor la función de cada herramienta y como se la puede aplicar.
